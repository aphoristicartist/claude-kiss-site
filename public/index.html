01

The principle

The smallest complete, robust solution.

KISS points at the harness, not at the quality of the work. Concise does not mean incomplete. Fewer tools does not mean fewer standards.

  • Questions stay questions.Edit only when the request calls for an edit.
  • Small fixes stay small.Repair the root cause and preserve unrelated work.
  • Complete means complete.No stubs, hardcodes, swallowed errors, or test-only shortcuts.

02

The surface

Six core defaults. Four quick switches.

The launcher requests six coding tools by default. Add a common capability when the task needs it, and combine switches when it needs more.

Core default

06
  • Bash
  • Glob

Quick switches

04
CLAUDE_KISS_WEB=1
WebFetch + WebSearch
CLAUDE_KISS_SKILLS=1
Your skills
CLAUDE_KISS_DELEGATION=1
Agent delegation
CLAUDE_KISS_MCP=1
MCP discovery, tool search + resources

Managed defaults suppress bundled workflows, official marketplace autoinstall, Claude.ai skill sync, Chrome integration, agent view, artifacts, connectors, remote control, and auto memory. Native CLI overrides, settings, hooks, and plugins remain live and can change the effective surface. EndConversation may also appear conditionally as a safety tool; it does not add file access.

03

The control

Plain files. Visible choices.

Inspect the effective launch before it runs, or copy the managed defaults once and make them yours. Updates never overwrite user-owned configuration.

CLAUDE_KISS_DRY_RUN=1 claude-kiss

Own the defaults

Run claude-kiss init. From then on, these three files belong to you:

~/.config/claude-kiss/
  prompt.md
  settings.json
  memory/CLAUDE.md

Evidence

Measure the files, not the pitch.

The repository includes eight paired tasks: same fixture, prompt, model, and budget; ordinary claude versus claude-kiss. The evaluator checks the resulting files, not just the prose.

Read the evaluator Read the case

Trust boundary

Strong defaults are not a sandbox.

Bash remains powerful. User, project, and local settings—and their hooks and plugins—still load. Explicit native flags can replace managed defaults. Tool limits shape attention, not filesystem access. Review permissions, repository settings, plugins, and MCP configurations as code.
